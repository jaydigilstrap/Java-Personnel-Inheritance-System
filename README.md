A Java project demonstrating object-oriented programming using inheritance.

## Features

- Base Person class
- Employee subclass
- Contractor subclass
- Constructor chaining with super()
- Encapsulation
- Getter and setter methods
- Salary management
- Hourly wage management
- Vacation day tracking

## Concepts Demonstrated

- Inheritance
- Encapsulation
- Constructors
- Method reuse
- Object-oriented programming
